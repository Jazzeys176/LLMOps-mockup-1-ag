# Smart Factory AI LLMOps System

## Problem Statement
The Smart Factory AI LLMOps System is a modular, production‑ready solution designed to monitor and manage large language models (LLMs) deployed in industrial environments. It ingests logs from an LLM‑powered factory assistant, computes key command‑center KPIs, detects quality drift in real-time, and surfaces actionable insights in interactive dashboards. The system is architected to provide deep visibility through trace and session explorers, comprehensive evaluator management, and prompt versioning. It lays the groundwork for advanced capabilities like dataset evaluation, annotation queues, alerting, and audit logs. By supporting AI‑generated root‑cause analysis (RCA) and human‑friendly recommendations, the platform ensures that factory AI assistants remain reliable, accurate, and safe, while being extensible for new models and datasets.

## Technologies Used

- **Python**: Core programming language for backend services and logic.
- **DuckDB**: Fast in-process analytical SQL database for efficient data storage and querying of analytics.

- **Azure SDKs & Boto3**: Libraries for cloud interactions (Azure Data Lake, AWS S3) for future scalability.
- **OpenAI API**: Integration for LLM-based evaluations and generation tasks.

### Frontend
- **React (v19)**: Library for building user interfaces.
- **Vite**: Next-generation frontend tooling for fast development and building.
- **Tailwind CSS**: Utility-first CSS framework for rapid and responsive UI design.
- **Lucide React**: Clean and consistent icon library.
- **Recharts**: Composable charting library for building data-rich dashboards.
- **React Router**: Declarative routing for React applications.

### Machine Learning & Data
- **Pandas**: Data manipulation and analysis.
- **Scikit-learn / Custom Drift Detection**: Algorithms for detecting data and concept drift.

## High-Level Workflow

The application follows a modern decoupled architecture:

1. **Ingestion**: Raw logs from the Factory Assistant are ingested via the API or generated by the mock data service.
2. **Processing Layer**: 
    - **Ingestion Service**: Normalizes and structures log data.
    - **Drift Service**: Analyzes incoming data patterns against baselines to detect anomalies.
    - **Evaluator Service**: runs LLM-as-a-Judge evaluations on interaction traces.
3. **Storage**: structured data is stored in **DuckDB** for fast analytical queries, while model artifacts and experiments are tracked in **MLflow**.
4. **API Layer**: **FastAPI** endpoints expose analytics, traces, sessions, and configuration to the frontend.
5. **Presentation**: The **React** frontend consumes APIs to render real-time dashboards, trace details, and configuration interfaces.

## How to Install and Run

### Prerequisites
- Python 3.10+
- Node.js 18+
- npm

### 1. Backend Setup

Navigate to the root directory and install Python dependencies:

```bash
# Create a virtual environment (optional but recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
make install
# OR manually: pip install -r backend/requirements.txt
```

Run the backend server:

```bash
make run-backend
# OR manually: uvicorn backend.api.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`. API Docs are at `http://localhost:8000/docs`.

### 2. Frontend Setup

Open a new terminal, navigate to the `frontend` directory:

```bash
cd frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```

The application dashboard will be available at `http://localhost:5173` (or the port shown in your terminal).

## Current Scope
The following features are currently implemented and functional:
- **Main Dashboard**: High-level KPIs, charts, and system health overview.
- **Tracing**: Detailed views of individual LLM traces, including latency, token count, and cost.
- **Sessions**: Exploration of user sessions and interaction history.
- **Evaluators**: Management of evaluation criteria and scorers.

## Future Scope
The following features are planned for future development:
- **Annotation Queues**: Workflows for human feedback and data labeling.
- **Prompts**: Versioning and management of prompt templates.
- **Datasets**: Management of test and evaluation datasets.
- **Alerts**: Real-time notification system for anomalies and threshold breaches.
- **Audits**: Comprehensive logs of system changes and user actions.
- **Settings**: System-wide configuration and preferences.
- **Guardrails**: Safety and compliance checks for LLM outputs.
